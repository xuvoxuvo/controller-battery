# 疑难排查

面向普通用户。构建、发布相关的问题见 [development.md](development.md)，协议细节见 [protocol.md](protocol.md)。

## 托盘图标没出现

1. **Windows 11 会折叠新图标**：点任务栏的「^」找电池图标；或者右键任务栏 →「任务栏设置」→「其他系统托盘图标」→ 打开 Controller Battery，让它常驻。这是系统行为，程序无法强制图标出现在任务栏上。
2. **「隐藏到托盘」是灰的**：说明托盘图标没注册成功，程序通常处在受限环境（低完整性进程）。请从资源管理器双击 exe 启动；程序每 5 秒自动重试，条件满足后菜单会自动可用。
3. **以管理员身份运行时图标在、但点击/退出没反应**：旧版本会被 Windows 的 UIPI 拦掉 Explorer 发来的托盘回调；当前版本已对托盘消息放行。请确认用的是最新构建。
4. **exe 所在目录带 `Low` 完整性标签**：`icacls <目录>` 里能看到 `Mandatory Label\Low Mandatory Level` 时，从该目录启动的 exe 一律被降级运行。把 exe 复制到普通目录（如 `C:\App\ControllerBattery`）再运行即可。
5. **卡片被隐藏、图标又不见了**：Explorer 重启等原因会丢图标，程序检测到后会自动把卡片放回来；仍找不回时，结束 `controller-battery.exe` 再启动。
6. **反馈问题**：附上 `%LOCALAPPDATA%\ControllerBattery\tray.log`，里面记录了错误码、进程与 shell 的完整性级别、会话号。

## 电量不更新或显示 `--`

- 手柄空闲时会停止上报，插拔充电线也不触发刷新——按一下键或推一下摇杆。
- `--` 与「未报告电量」表示该手柄（或当前连接模式）不提供电量信息，例如 XInput 下的第三方手柄；切到蓝牙通常能读到。
- 蓝牙 DualSense 显示 `≈` 与「状态未知」，表示收到的是电量不刷新的简化报文，程序会尝试切回全量报文；持续出现时断开重连一次。

## 卡片不见了或位置不对

- 卡片可能被隐藏到了托盘：左键点托盘图标，或右键菜单选「显示卡片」。
- 启用了「空闲时自动隐藏」时，手柄停止上报约 1 秒后，行内会显示「3 秒后隐藏」；没有手柄时显示「未检测到手柄，3 秒后隐藏」，随后淡出收起（卡片正在前台时不会），手柄重新上报后自动出现。点击或拖动卡片会立即取消倒计时；淡出已经开始时也会被打断并恢复显示。手柄断开后约 1 秒卡片会回到「未检测到手柄」界面。从托盘显示后有 5 秒缓冲。第一次收起会提示托盘图标的位置和退出方式；想关掉就先点托盘图标显示卡片，再右键取消勾选。
- 已经启动时再次双击 exe 不会开第二份，只会把现有卡片显示出来。
- 位置记在 `%LOCALAPPDATA%\ControllerBattery\settings.json`；删掉这个文件再启动会回到默认位置，也能解决卡片被拖到屏幕外的情况。
