# PS5 手柄电量小浮窗

一个 200×76（逻辑像素）的桌面小卡片，实时显示 DualSense 手柄电量。纯 PowerShell + 系统 HID 接口，不需要任何驱动或运行时。

![浮窗](preview.png)

## 用法

**双击 `查看手柄电量.cmd`** —— 右下角出现浮窗。

命令行查一次：

```powershell
powershell -ExecutionPolicy Bypass -File .\DualSenseBattery.ps1 -Once
```

## 显示的含义

| 显示 | 含义 |
| --- | --- |
| `25%` + `使用中` / `充电中` / `已充满` | 手柄在发**全量报文**，数值可信 |
| `≈25%`（灰色）+ `状态未知` | 手柄在发**简化报文**，其中的电池字段不更新，只能当参考 |
| `25%`（灰色）+ `空闲` | 一段时间没收到新报文，显示的是最后一次读数 |
| `--` + `未检测到手柄` | 没找到设备（没配对 / 没插线 / 已关机） |
| `--` + `读取失败` | 设备打不开，通常是别的程序独占了手柄 |

右键菜单：立即刷新 / 开机自动启动 / 退出。左键拖动可移动，位置会记住。

## 为什么会有「≈ 状态未知」

DualSense 在蓝牙下会发两种输入报文，实测（同一物理状态、没插线）：

| 报文 | 长度 | `status[0]` | 解读 |
| --- | --- | --- | --- |
| `0x31`（全量） | 78 | `0x02` | 25%、放电中 ✅ |
| `0x01`（简化） | 78 | `0x12` | 25%、充电中 ❌（字段停在插线时的旧值） |

简化报文的 `status[0]` 不随插拔刷新，整条报文也可能长时间逐字节不变。工具因此只对 `0x31`（以及 USB 的 64 字节 `0x01`）显示充电状态；遇到简化报文时把数字标记成 `≈`、状态标为 `状态未知`，避免显示一个过期的「充电中」。

## 另外两个手柄行为

1. **空闲时停止上报**。蓝牙下手柄只在有输入变化时发报文，不动就不发；Windows 会把你最后一条报文原样返回。所以工具按报文指纹判断是否还在刷新，超过 5 秒没变化就标 `空闲`。
2. **插拔充电线不会立刻反映**。拔插本身不产生输入事件，读数要等你按一下键或推一下摇杆才会刷新。**想确认当前状态，动一下手柄再看。**

## 原理

DualSense 的 HID 输入报告里有一个 `status[0]` 字节：

| 位 | 含义 |
| --- | --- |
| 低 4 位 | 电量档位 0–10（每档 10%，按 `档位×10+5` 折算） |
| 高 4 位 | 充电状态：0 放电、1 充电、2 已充满、0xA/0xB 电压或温度异常、0xF 充电错误 |

字节位置：USB 报告 `0x01`（64 字节）在偏移 **53**；蓝牙报告 `0x31`（78 字节）在偏移 **54**（多一个头字节）。与 Linux 内核 `hid-playstation.c`、第三方实现一致。

## 常见问题

**双击 .cmd 提示「未知发布者 / 无法验证发布者」**
PowerShell 脚本和批处理没有数字签名，从网上下载或从别的机器拷来的文件会被 Windows 拦一次。右键文件 → 属性 → 勾选「解除锁定」；或执行：

```powershell
Get-ChildItem -Recurse | Unblock-File
```

脚本内容全在这个文件夹里，可以直接打开核对。

**显示「未检测到手柄」**
检查：是否已和这台电脑蓝牙配对（或插好 USB 数据线）、是否按过 PS 键唤醒、设备管理器里有没有 `Wireless Controller`。ViGEmBus 与读电量无关。

**显示「读取失败」**
多半是别的程序独占了手柄（DS4Windows、某些游戏平台的手柄映射）。关掉后再试，或插 USB。

**数值和别处不一样**
电量是 10% 一档的粗值，差一档很正常；`空闲` 或 `≈` 状态下显示的不是实时值。

## 文件

| 文件 | 说明 |
| --- | --- |
| `DualSenseBattery.ps1` | 主程序：浮窗界面 + HID 读取 |
| `查看手柄电量.cmd` | 双击启动（后台运行，无控制台窗口） |
| `preview.png` | 界面截图 |

参数：`-Once`（只输出一次）、`-InstallStartup` / `-RemoveStartup`（开机自启）、`-Diag`（排查高 DPI 缩放问题）。

## 备选方案

- **DS4Windows**：功能最全，主界面和托盘提示里都有电量；但要装 .NET，且会接管手柄输入。
- **Steam**：设置 → 控制器 里能看到已识别手柄的电量，前提是 Steam 接上了这个手柄。
- **Windows 设置 → 蓝牙和设备**：部分系统会给蓝牙设备显示电量，刷新慢、也不一定出现。
